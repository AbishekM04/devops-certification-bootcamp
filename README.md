

# DevOps Certification Boot Camp

## About

This repository documents my hands-on learning and practical work completed as part of a **DevOps Certification Boot Camp**.

The repository covers DevOps fundamentals, Linux, Git and GitHub, cloud computing with AWS, Docker, Kubernetes, CI/CD with Jenkins, shell scripting, monitoring and observability, and DevSecOps practices.

It also contains practical commands, configurations, YAML manifests, scripts, screenshots, troubleshooting notes, and capstone project documentation.
